Google-sleutel

Eenmalig invullen op deze computer. De sleutel blijft alleen in deze browser en gaat nergens anders heen dan naar Google.

Hoe kom ik aan een sleutel?
  1. Ga naar console.cloud.google.com en maak een project (bijv. "PlaatsRadar").
  2. Koppel een betaalaccount (verplicht bij Google; de eerste 1000 opzoekingen per maand zijn gratis).
  3. Zet Places API (New) aan (APIs & Services → Library).
  4. Credentials → Create credentials → API key. Beperk de sleutel tot Places API (New).
  5. Zet bij Quotas een daglimiet (bijv. 100 per dag), dan kan het nooit duur worden.
